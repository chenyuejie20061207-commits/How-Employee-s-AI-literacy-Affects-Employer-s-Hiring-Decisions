## 5. 字段完整性与正文质量

- JD 正文长度：最短 103 字，中位数 380 字，最长 1976 字。
- 正文中同时出现“职责”和“要求/任职”标题的 JD：154/400（38.5%）。该比例只描述排版习惯，不是正文完整率；不少 JD 用编号段落写职责与要求，已由独立复核确认。
- 未披露字段数量（不根据企业名称猜测）：行业 94 条；企业性质 70 条；企业规模 400 条。
- 行业缺失较高的原因是校招宝开放岗位对象和公开快照均未提供行业；能从同一企业公开记录或企业档案确认的已回填。企业规模在所用公开接口中没有字段，因此全部保留“未披露”，这是本数据的主要限制，不能在后续分析中把“未披露”当作某一种规模。
- 素材 ID 唯一性、文本哈希一致性、URL 有效性、时间格式、PII 残留和重复组检查：全部通过。

## 6. 去重与脱敏

- 输入 JD 候选 499 条，精确去重后 495 条，精确重复移出 4 条。
- 相似度阈值 92 的近似重复候选 48 对、24 组；经核对这些记录多为不同专业方向、不同企业或不同城市的独立招聘页，未按文本相似度直接删除，而按“同城市 + 同企业 + 同岗位名称”继续合并 12 组。
- 同一岗位被多个城市检索命中的 ID 处置 0 组；所有近似组在正式表中不再保留未处理的 `重复组ID`。
- PII 校验：手机号、邮箱、身份证号、固定电话、QQ、微信、联系人姓名等扫描结果 0 条残留。
- 上游编码异常：22 条正文含少量 Unicode 替换字符，已统一替换为 `□` 并重算哈希；未猜测补字，明细在 `质量核查记录.json`。
- 结构素材使用“结构抽象v1（不含原文）”，不保存真实姓名、学校班级、联系方式或示例简历原文。

## 7. 自动校验缺口与限制

目标配额全部满足。

仍需明确的研究限制：

1. 数据来自公开招聘信息的限量研究抽样，不是招聘市场总体，不能推断总体岗位分布。
2. 校招宝开放 API 的 JD 正文由该平台从公开渠道整理；本项目只对可匹配到公开快照原始链接的记录纳入正式数据，但不保证原发布页当前仍在线。
3. 岗位类型采用标题优先的操作化规则，边界岗位仍可能因企业命名差异存在分类误差；独立复核对明显错分的岗位已作重分类记录。
4. 行业、企业性质和企业规模未公开时统一为“未披露”，没有按企业名称推断；公开接口未提供企业规模时，本表不做估算。
5. 自动校验和独立内容复核不能替代小组第二人的人工复核；正式 CSV 因此不写“已通过”。
