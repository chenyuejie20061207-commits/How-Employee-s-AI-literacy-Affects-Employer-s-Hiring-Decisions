# 量表修订说明

## 1. 修订依据

- `AI 能力量表.csv` 与开题报告第四、五部分：原量表按 AI/计算机相关专业定义，L5 以“10B+ 参数预训练、Ring Attention、MoE 路由”等顶尖科研场景为锚点。
- 任务一交付的 `原始素材_岗位与简历结构.csv`：覆盖 IT/技术、管理、非常规认知、常规四类岗位，96 条 `VAI-` 平行条目在技能、项目、实习、教育四个栏目预埋 L0—L5 信号；大量非技术岗位的表达需要更贴近实际简历的层级描述。
- 隐私与实验约束：学历、专业、成绩、实习经历为控制变量，AI 表述只在技术细节与复杂度上递进；所有范例须虚构化。

## 2. 逐层级修订

| 层级 | 原描述/范例要点 | 修订后描述/范例 | 调整原因 |
|---|---|---|---|
| L0 | “简历中无任何 AI/ML 关键词” | “手工、纸质、线下完成任务，未使用数字工具”；范例：“手工绘制程序流程图并纸质归档”“人工核对纸质台账” | 原定义把“没写 AI”当成 L0，会把 Excel 用户误判为 L0。任务一 L0 锚点是手工流程，修订后与数据一致且可观察。 |
| L1 | “仅使用通用 AI 工具，如 ChatGPT 检索和文档撰写；课程用过 Scikit-learn” | “使用办公软件或常规业务系统完成记录、统计与呈现”；范例：“用 Excel 函数与数据透视汇总缺陷记录” | Scikit-learn 属机器学习库，应归 L3；通用聊天工具单独作 L1 会高估非技术岗位的数字化基础。按字段字典 L1=数字化基础统一口径。 |
| L2 | “用 Copilot 辅助写代码/调试” | “用 Python、SQL、脚本或程序批量处理数据”；范例：“编写 Python 脚本自动清洗数据表”“SQL 多表查询生成报表” | Copilot 辅助属现成 AI 工具，按修订规则归 L3；L2 需要可复用的自动化能力证据，且与任务一预埋锚点一致。 |
| L3 | “API+LangChain 搭建问答、复现 ResNet” | “调用现成 AI/分析工具或模型 API 解决业务问题，含 BI 看板、OCR、AIGC 辅助”；范例：“调用机器学习库训练分类模型”“用 BI 看板监控人效指标” | 原范例偏 CS 专业；非技术岗位更多使用 BI/OCR/AIGC。保留 API 与模型库调用，纳入业务工具，覆盖四类岗位。 |
| L4 | “LoRA 微调、RAG pipeline、Agent 系统、F1 0.87” | “搭建 RAG、Agent、提示词模板、知识库问答等应用级系统，具备评估与数据清洗能力”；范例：“搭建知识库问答 Agent（向量检索+RAG）”“设计提示词模板并沉淀复用” | 原范例指标过细、难在普通简历出现；保留系统构建内核，增加提示词资产化等更常见的简历表述，删除虚构企业名与具体指标。 |
| L5 | “主导千亿参数预训练、改进 Attention、百卡集群 MFU 45%” | “主导模型训练方案、评估框架、前沿架构验证或部门 AI 落地规划”；范例：“设计模型评估框架与训练方案”“制定部门 AI 应用规划与数字协作机制” | 原定义仅适配顶尖算法岗，对管理/常规岗位不可观测。修订为“研究/战略”双通道：顶尖技术成果仍作特例，业务侧以规划与评估体系为 L5 信号。 |

## 3. 结构性调整

1. **从专业量表转为简历信号量表**：每级同时给出“能力定义—关键词—项目描述特征—判定边界”，便于从分散栏目中识别。
2. **栏目适配**：范例分别落在教育背景、实习经历、项目经历、技能四类栏目，避免只出现在“技能”栏。
3. **控制变量保护**：所有范例沿用同格骨架，仅 AI 子句随层级变化；学历、专业、时间、量化占位符、机构属性保持一致。
4. **虚构化**：机构使用 `虚构机构名登记表.csv` 中的虚构专名，院校使用泛化类别，量化使用“约 N”占位；不写真实姓名、手机、邮箱、具体学校班级。
5. **保留项**：L3 的 API/模型库调用、L4 的 RAG/Agent/微调、L5 的预训练与架构创新继续保留，作为技术岗高等级信号；只是不再作为唯一范例。
6. **教育背景栏目改写**：删除原“主修方向”这一在现实简历中极不自然的字段标签，把 AI 信号并入“课程实训涉及……等技能”，后接原有的需求梳理、实现与验收全流程和课程设计量化；学历、专业、时间、成绩等控制变量及六级骨架不变，避免一眼被识别为实验文本。

## 4. 对分类结果的影响

按修订规则对 96 条 `VAI-` 条目独立核定，92 条与预埋等级一致，4 条修订：
- `VAI-NRC-INT-05`：预埋 L2 → L4。“设计提示词体系批量生成研究摘要”已形成可复用的提示词工程资产，按 L4 边界不应停留在脚本自动化层。
- `VAI-MGT-EDU-05`、`VAI-MGT-INT-05`、`VAI-REG-PRJ-05`：预埋 L4 → L3。“引入/辅助起草”“调用大模型做单据信息抽取”属于调用现成大模型完成单一任务，未搭建 RAG/Agent/微调或提示词体系，按修订边界归 L3。

含 AI 相关表述的岗位 JD 按需求侧口径归类并标记为不可用于虚拟简历。结构素材因不含可归级表述未入表。总体说明任务一预埋等级基本可用，但需任务二按统一边界做独立核定。
